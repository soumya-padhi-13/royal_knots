# Royal Knot Films 💍🎥

An end-to-end wedding photography and cinematography portfolio website built to showcase wedding stories, service packages, and client booking inquiries.

🌐 **Live Demo:** [Royal Knot Films](https://soumya-padhi-13.github.io/royal_knots/)

---

## ✨ Features

* **Responsive Design:** Clean, mobile-friendly layout tailored for desktop, tablet, and mobile viewing.
* **Portfolio Showcase:** Highlights curated wedding films, candid photography, and pre-wedding shoots.
* **End-to-End Service Overview:** Details complete wedding coverage from pre-wedding ceremonies to final film delivery.
* **Single-Page Architecture:** Fast-loading static build contained cleanly within `index.html`.
* **GitHub Pages Ready:** Configured for seamless static deployment.

---

## 🛠️ Tech Stack

* **HTML5** – Semantic structure and layout
* **CSS3** – Styling, responsive grids, and visual presentation
* **Google Fonts** – Custom typography for an editorial wedding aesthetic
* **GitHub Pages** – Static site hosting
